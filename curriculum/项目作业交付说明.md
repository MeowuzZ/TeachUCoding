# 本地项目作业

覆盖 1111 节，12 类生活场景，24 种项目证据形式。

- 社区共享书屋：图书借阅从登记、借出到归还；逾期与库存为扩展模块
- 合租家庭账本：室友登记生活支出，核对账单并完成结算
- 社区报修服务台：居民登记故障，物业接单并记录处理结果
- 周末活动报名站：社区活动收集报名并完成签到
- 社区团购配送台：邻里团购收集需求、准备商品并交付
- 邻里宠物照护预约：居民登记照护请求，确认并完成服务
- 家庭旅行筹备板：整理旅行物资和开销，核实并准备就绪
- 学习资料研习站：登记学习资料，组织研读并保留复盘
- 校园器材借用中心：社团借用器材，确认领用与归还
- 社区志愿服务中心：居民报名志愿任务，确认参加并核对工时
- 社区花园养护台：登记养护事项并追踪执行情况
- 校园闲置交换集市：登记闲置物品并追踪交换交接

基础包采用 Web 本地存储、Java 命令行业务引擎或 Python/SQLite 服务三种实现。框架课程可在基础切片上迁移实现，不将标准库实现称为 Spring/Vue 完整系统。标准答案覆盖基础切片；大型项目扩展需按各章知识继续实现。
